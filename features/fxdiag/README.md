# FX diagnostic overlay (temporary)

Debug: bottom lines on every screen with the edit mode, the stored master FX params, TE's master FX object / vtable / process pointer, and call counters of RESO, SHIMMER and FXPACK's stereo and mono process. Observes only.

Status: experimental. License: MIT.

## Open it on the OP-1

Nothing to open: not part of `op1plus` — compose and flash `recipes/op1diag.json` (boot text `op1sdk D`); the diagnostic lines sit at the bottom of every screen.
