# WARP synth engine — spec

Status: **v0.1** (2026-10-13): built and sim-verified, awaiting device test. Code: `features/warp/`
(on the engine host, tag 6). Idea: phase warps on a single-cycle wave (strudel's worklets, AGPL:
ideas only, own code).

## What it is

One of 8 single-cycle waves read through one of 16 warps. TE's envelope, velocity, volume, FX, LFO,
glide, bend and sequencers apply as for any engine.

| page | blue | green | white | orange |
|---|---|---|---|---|
| 1 | **WAVE** SINE TRI SAW SQUARE PULSE HALF ORGAN VOX | **MODE** (16, below) | **AMOUNT** (0 = plain wave) | **COLOR** lowpass (0 = open) |
| 2 | **SWEEP** amount added at note on | **DECAY** of the sweep, 10 ms .. 4 s | **MOTION** LFO on the amount (faster + deeper) | **UNISON** second osc, up to ~20 cents |
| 3 | the sound's FX knobs (engine host, as WHEEL) | | | |

Modes: **BEND** (Casio-CZ phase distortion), **SYNC** (hard sync 1 .. 7.5x), **MIRROR**, **FOLD**
(output wavefolder, gain 1 .. 8), **QUANT** (phase steps 16 .. 2 bits), **SQUEEZE** (phase power
curve), **PINCH** (S-curve), **WRAP** (sine phase modulation), **FM** (the wave modulates its own
phase), **GAP** (wave squeezed into 100 .. 10 % of the cycle, silence after), **BITREV**
(bit-reversed phase), **CHAOS** (logistic map), **STAIR** (output bit depth 16 .. 3), **HARM**
(integer harmonic 1 .. 8), **RING** (ring mod with a sine at 1 .. 8x), **XOR** (phase bit flips).
Amount 0 is the plain wave in every mode.

- Engine list **warp**; preset browser folder **warp** with one preset **warp** (CZ-bass-like);
  **shift + blue turn** on the engine screen browses 16 built-in sounds (CZ BASS, SYNC LEAD, FOLD
  PAD, GLASS, MIRROR KEY, BITCRUSH, PLUCK, PINCH VOX, WRAP BELL, GAP CHIP, BITREV FX, CHAOS, STAIR
  BASS, HARMONICS, RING METAL, XOR GLITCH).
- Engine screen: one cycle of the warped wave (as set, without sweep / motion), wave and mode
  names, the page's knobs.

## How

- Host: `features/enginehost` (drwave render / note_on slots), tag 6: slots 5-8 = `0x6000 | v`,
  page 1 in slots 1-4 as 0..16383; all inside drwave's ranges (boot check passes, loads on stock as
  drwave).
- DSP (`warp_core.c`): 32-bit phase per voice, its top 16 bits through the warp, 256-point tables
  (`wp_tables.h`, generated by `gen_tables.py`) with linear interpolation, at TE's 88.2 kHz voice
  rate. Warp constants every 32 samples from AMOUNT + SWEEP x env + MOTION x LFO, ramped across
  the block. One loop per mode (the warp is inlined with a constant mode).
- Cost (sim, per 128-sample voice block): plain sine 9.9k cycles, SAW + SYNC 8.1k, FM + unison +
  colour + motion + sweep 18.1k (WHEEL FULL 19k, TE's voltage 16.7k).

## Tests

1. `features/warp/test_warp_core.c` (79 checks, ASan/UBSan clean): clean sine at pitch, amount 0 =
   plain wave in all 16 modes, every mode at full: bounded / sounding / brighter, phase warps keep
   the fundamental (except GAP, BITREV, HARM, RING by design), all waves differ, sweep decays,
   motion moves the spectrum, unison, colour darkens, screen cycle, repeatable notes, extremes.

   and tag 5 to WHEEL, 441 Hz pitch, restart, paging, page-1 clamp, page-2 tag kept, bank (16
   entries in range, wraps), page-3 FX knob, engine-list renames chained, cycles, screen draw.
