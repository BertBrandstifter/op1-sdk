# CHORD+ chord keyboard — spec

Status: **v0.3** (2026-10-13): bigger panel (nearly full screen, size 2-3 text). v0.2: toggle moved to **shift + insert** (the live quantizer left op1plus at
the user's request; requantize stays). v0.1: shift + insert. Code:
`features/chordplus/` (first in recipe `op1plus`). Idea: sloop's chord keyboard (white keys = scale
chords, black keys = modifiers), ideas only, own code.

## What it does

**Shift + insert** turns the synth keyboard into a chord keyboard:

- **White keys** play the seven chords of the chosen key and scale: C = I, D = ii, E = iii, F = IV,
  G = V, A = vi, B = vii° (in C major: C, Dm, Em, F, G, Am, B°). The key's octave stays the key's
  octave; KEY transposes (KEY D: the C key plays D major).
- **Held black keys** change the next chord and make no sound:

| black key | modifier |
|---|---|
| C# | major ↔ minor third |
| D# | + 7th (diatonic: Cmaj7, Dm7, G7, Bm7b5) |
| F# | third → fourth (sus4) |
| G# | + 9th |
| A# | inversion (hold two A# for the second inversion) |

  Modifiers combine (D# + G# = 9 chords). A small badge top right shows CHORD and the last chord's
  name (e.g. `DMIN7`).

## Panel

Turning CHORD+ on opens the panel for 3 s (every change restarts the 3 s). Shift + insert
while CHORD+ is on and the panel is closed opens it again; while the panel is open it turns
CHORD+ **off**. Panel knobs (one step per detent):

| blue | green | white | orange |
|---|---|---|---|
| **KEY** C .. B | **SCALE** major, minor, dorian, mixolydian, harmonic minor, phrygian, lydian | **VOICING** CLOSE, LEAD (voice leading: the inversion nearest the previous chord), OPEN (drop 2), BASS (+ root an octave down) | **STRUM** 0 (off) .. 100 ms, 5 ms steps |

Settings live in RAM: after a reboot CHORD+ is off, C major, CLOSE, no strum.

## How

- Shared points `kb_note_on` / `kb_note_off` (filter, `"order": "first"`): a white key's note-on is
  consumed and replaced by its chord; every chord note is passed on through the rest of the chain
  (`compose_kb_note_on`, generated by the composer: requantize logs it, the quantizer may hold it
  to the grid) and played by TE (`TE_VOICE_NOTE_ON`) if nobody takes it. A re-entry flag keeps
  CHORD+ out of its own notes. Note-off releases the chord the key started (stored per key).
  Notes shared by two held chords sound once and stop with the last chord (counted per note).
- **Strum**: the notes go to the Seq thread (single-producer ring, `seq_tick`) and play one after
  another at the strum spacing (64-sample resolution); a release before a strummed note drops it.
  Strummed chords bypass the quantizer (it is single-producer per thread; documented limit).
- `on_key` filter: shift + insert (down and up consumed; plain insert stays TE's).
  `on_knob` filter (`order: first`) while the panel is open. `frame` (`order: last`): badge and
  panel over every page, including the WHEEL / LOFI screens.
- New composer option (2026-10-13): `"order": "first" | "last"` per shared handler, overriding
  recipe order for that handler. Requantize's keyboard handlers changed from observe to a
  never-consuming filter with `order: first`, so they run after CHORD+ and log the chord notes
  (not the raw keys / modifier keys) during a take.
- Synth playmode only. MIDI in and the sequencers get the plain keys: sequencers record and play
  the root key (they take key presses on their own path), arpeggio included.
